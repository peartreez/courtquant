# Changelog

## [1.3.0] - 2026-11-03
- Added dual regional support for **US DFS (`us_dfs`)** and **US Exchanges (`us_ex`)** (PrizePicks, Underdog, Kalshi, Polymarket, Novig, etc.).
- Implemented robust dataframe and recommendation deduplication to filter out repeat odds entries.
- Updated documentation and README for California-compliant DFS and exchange execution.

## [1.2.0] - 2026-10-30
- Added automated wager recommendation scanner with fractional Kelly position sizing.
- Extended data ingestion pipeline through current 2026 tournaments.

## [1.1.0] - 2026-10-30
- Added Odds API Integration and CLV Tracking module.
- Refactored Streamlit dashboard for modern layout parameters.
